# 隙みせ攻撃(レスの文章)の一覧

このファイルは、`node scripts/bait-list.js` で自動で作る。文章を直すときは、**ここの「番号」を伝えてもらえれば**、元のデータ(下に書いた場所)を書き換える。

- **プレイヤー対戦**の隙みせ攻撃(プレイヤーが打つ。5種類から選ぶ): `js/pvp.js` の `BAIT_LINES`。打つたびに、その種類の中から、ランダムに1つ出る。
- **NPC 戦**の隙みせ攻撃(NPC のレス): `js/data.js` の、NPC ごとの `lines`。出るたびに、その種類の中から、ランダムに1つ出る。
- 文章は、**種類の見た目**(長文は枠が大きい / 感情論は赤く震える / ブーメランは紫の波線 / 論点ずらしは斜め / 短文連打は大きな字)で、見分ける手がかりにもなる。種類に合った文章にする(長文は、長めに)。
- `{n}` `{id}` のような記号は、出るときに、レス番号・ID に置き換わる。残しておく。
