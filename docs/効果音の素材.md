# 効果音の素材(フリー素材)

2026-11-08 から、攻撃の音・ゲーム開始の音の一部に、**フリーの効果音素材**を使う。そのほかの音(キー・誤字・ミス・勝敗・UI・BGM など)は、これまでどおり、WebAudio で合成している。

## 2. 使っている素材と、割り当て
| キー | 素材(効果音ラボでの名前)| 長さ | 使いみち |
|---|---|---|---|
| `whip2` | 鞭で攻撃2(先端が音速を超える) | 0.63秒 | **長文**の着弾(スパーン!) |
| `bomb1` | 爆発1(チュドーン) | 3.40秒 | **感情論**の発射(バン!。押した瞬間)。2026-11-08 に、爆発2 から変更(「重すぎる」との指摘) |
| `robot1` | ロボットを殴る1(鈍い金属音) | 1.06秒 | **感情論**の着弾(金属に当たる鈍い音) |
| `heavypunch1` | 重いパンチ1(強烈な殴打) | 1.06秒 | **ブーメラン**の着弾(重く刺さる) |
| `bigpunch` | 大パンチ(必殺技ヒット) | 1.31秒 | **論点ずらし**の着弾(切り返しの一撃) |
| `submg2` | サブマシンガン発射2(長めの連射) | 2.14秒 | **短文連打**の発射(マシンガン。押した瞬間) |
| `finisher` | 必殺技ヒット(とてつもなく重い一撃) | 1.36秒 | **ゲーム開始**(BATTLE START)に、従来の音へ重ねる |
- **割り当ての表**は、`js/audio.js` の `SE_MAP`(攻撃の種類 → 発射・着弾)・`SE_LAYER`(従来の音に重ねるサンプル)・`SE_GAIN`(聞こえの大きさをそろえる倍率)。ここを書き換えれば、差し替えられる。
- 表で `null` のところは、**従来の合成の音**(発射 = `shot` / 着弾 = `impact`)。長文・ブーメラン・論点ずらしの発射、短文連打の着弾が、これに当たる。待たせ煽り・いなす・「効いてて草」は、すべて従来の音。
- **長さは、まだ調整していない**(ユーザーの指示)。そのため、爆発(3.4秒)とマシンガン(2.1秒)は、押すたびに、最後まで鳴る。連打すると、重なる。
- 割り当ての根拠は、素材の名前と説明(聞こえ方は、私には確かめられない)。ユーザーが聞いて決めた素材を、使いみちの意味に合わせて、私が割り振った。違っていたら、差し替える。

## 3. 仕組み
- 素材のファイル(MP3)は、**無加工**のまま、`js/sfxdata.js` に base64 で埋め込む(`python3 scripts/build-se.py`。元のファイルは `se-raw/`)。`file://` で開いても鳴り、配布物(`public/`)にも自動で入る。約330KB。
- `index.html` が `js/sfxdata.js` を `js/audio.js` の前に読み込む。**最初の操作のあと**(`unlock()`)に、7個を `decodeAudioData` で読み込む。読み込み前・読み込めなかったときは、**従来の合成の音**で鳴る(音が出ないことはない)。
- 攻撃の種類は、カードが効くレスの種類(`counters[0]`)。複数に効くカード(「図星だったかな？w」)は、先頭の種類(感情論)。NPC 戦(`ui.js`)・プレイヤー対戦(`pvpui.js`。自分の攻撃も、相手の攻撃も)の両方で、同じ音が鳴る。
- 着弾のときは、素材(または従来の `impact`)に、コンボの音(`crit`)が、これまでどおり重なる。

## 4. 確かめたこと
- `node tests/run.js`: 540項目すべて成功(うち効果音 20項目: 7個の読み込み・割り当てのキーがすべて埋め込み済み・すべての素材が割り当て済み・種類ごとの鳴り分け・従来の音へのフォールバック・ミュート)。
- 実ブラウザ(Chromium): **7個とも MP3 として読み込めた**。種類ごとに、割り当てた素材の長さで再生されることを確認(長文の着弾 = 鞭 0.58秒、感情論の発射 = 爆発 2.55秒 など)。ゲーム内で、カードを撃っても、同じ素材が鳴る。
- **聞こえ方は、私には確かめられない。** 試聴は、`out/demo/se-preview.html`。
