# 効果音の素材(フリー素材)

2026-11-08 から、攻撃の音・ゲーム開始の音の一部に、**フリーの効果音素材**を使う。そのほかの音(キー・誤字・ミス・勝敗・UI・BGM など)は、これまでどおり、WebAudio で合成している。

## 2. 使っている素材と、割り当て
| キー | 素材(効果音ラボでの名前)| 長さ | 使いみち |
|---|---|---|---|
| `whip2` | 鞭で攻撃2(先端が音速を超える) | 0.63秒 | **長文**の着弾(スパーン!) |
| `bomb1` | 爆発1(チュドーン) | 3.40秒 | **感情論**の発射(バン!。押した瞬間)。2026-11-08 に、爆発2 から変更(「重すぎる」との指摘) |
| `robot1` | ロボットを殴る1(鈍い金属音) | 1.06秒 | **感情論**の着弾(金属に当たる鈍い音) |
| `heavypunch1` | 重いパンチ1(強烈な殴打) | 1.06秒 | **ブーメラン**の着弾(重く刺さる) |
| `bigpunch` | 大パンチ(必殺技ヒット) | 1.31秒 | **論点ずらし**の着弾(切り返しの一撃) |
| `submg2` | サブマシンガン発射2(長めの連射) | 2.14秒 | **短文連打**の発射(マシンガン。押した瞬間) |
| `finisher` | 必殺技ヒット(とてつもなく重い一撃) | 1.36秒 | **ゲーム開始**(BATTLE START)に、従来の音へ重ねる |
| `pistol` | 拳銃を撃つ | 1.41秒 | **隙みせ攻撃を打つ**音(プレイヤー対戦。自分が打ったとき)。2026-11-10 に、「ショット」から変更 |
| `sniper` | 狙撃銃をチャッと構える | 1.07秒 | **カードの引き直し**(NPC 戦・プレイヤー対戦。自分の分)。2026-11-10 に、「手裏剣を投げる」から変更 |
- **割り当ての表**は、`js/audio.js` の `SE_MAP`(攻撃の種類 → 発射・着弾)・`SE_LAYER`(従来の音に重ねるサンプル)・`SE_REPLACE`(従来の音の代わりに鳴らすサンプル。`bait` = 隙みせを打つ → 拳銃 / `reload` = 引き直し → 狙撃銃)・`SE_GAIN`(聞こえの大きさをそろえる倍率)。ここを書き換えれば、差し替えられる。
- 表で `null` のところと、**その他の攻撃**(待たせ煽り・いなす・「効いてて草」・自演乙)は、**共通の音 = 鞭で攻撃2**(`SE_DEFAULT`。2026-11-08 に、「割り当てのない攻撃は、鞭で統一」との指示で変更)。長文・ブーメラン・論点ずらしの発射、短文連打の着弾が、これに当たる。素材が読み込めないときだけ、従来の合成の音(`shot` / `impact`)で鳴る。
- **隙みせ攻撃を打つ音**は、自分が打ったときだけ「拳銃を撃つ」。**相手が打ったときは、従来の合成の音**(`tell`)のまま(相手の動きを知らせる音のため)。NPC 戦の隙みせ(NPC のレス)は、プレイヤーが打つものではないので、対象外。
- **引き直しの音**は、自分のカードを引き直したときだけ。以前、プレイヤー対戦の引き直しは、無音だった。今回、鳴るようにした。
- **長文は、発射も着弾も、鞭**(押した瞬間と、当たった瞬間に、2回)。NPC が、こちらに打ち返す音(詰め・必死で草・誤字のつっこみ)は、対象外で、従来の音のまま。
- **長さは、まだ調整していない**(ユーザーの指示)。そのため、爆発(3.4秒)とマシンガン(2.1秒)は、押すたびに、最後まで鳴る。連打すると、重なる。
- 割り当ての根拠は、素材の名前と説明(聞こえ方は、私には確かめられない)。ユーザーが聞いて決めた素材を、使いみちの意味に合わせて、私が割り振った。違っていたら、差し替える。

## 3. 仕組み
- 素材のファイル(MP3)は、**無加工**のまま、`js/sfxdata.js` に base64 で埋め込む(`python3 scripts/build-se.py`。元のファイルは `se-raw/`)。`file://` で開いても鳴り、配布物(`public/`)にも自動で入る。約400KB。
- `index.html` が `js/sfxdata.js` を `js/audio.js` の前に読み込む。**最初の操作のあと**(`unlock()`)に、9個を `decodeAudioData` で読み込む。読み込み前・読み込めなかったときは、**従来の合成の音**で鳴る(音が出ないことはない)。
- 攻撃の種類は、カードが効くレスの種類(`counters[0]`)。複数に効くカード(「図星だったかな？w」)は、先頭の種類(感情論)。NPC 戦(`ui.js`)・プレイヤー対戦(`pvpui.js`。自分の攻撃も、相手の攻撃も)の両方で、同じ音が鳴る。
- 着弾のときは、素材(または従来の `impact`)に、コンボの音(`crit`)が、これまでどおり重なる。

## 4. 確かめたこと
- `node tests/run.js`: 540項目すべて成功(うち効果音 20項目: 7個の読み込み・割り当てのキーがすべて埋め込み済み・すべての素材が割り当て済み・種類ごとの鳴り分け・従来の音へのフォールバック・ミュート)。
- 2026-11-08(追加分): `node tests/run.js` 573項目すべて成功(隙みせ = ショット / 引き直し = 手裏剣の割り当て・鳴らす回数・素材がないときの合成音を追加)。実ブラウザで、対戦の隙みせを打つと 0.81秒のサンプル(ショット)、引き直し(対戦・NPC 戦)で 0.64秒のサンプル(手裏剣)が鳴ることを確認した。
- 実ブラウザ(Chromium): **7個とも MP3 として読み込めた**。種類ごとに、割り当てた素材の長さで再生されることを確認(長文の着弾 = 鞭 0.58秒、感情論の発射 = 爆発 2.55秒 など)。ゲーム内で、カードを撃っても、同じ素材が鳴る。
- **聞こえ方は、私には確かめられない。** 試聴は、`out/demo/se-preview.html`。

## 6. 差し替えの記録(2026-11-10)
- 隙みせ攻撃を打つ音を、「ショット」から**「拳銃を撃つ」**に、カードの引き直しを、「手裏剣を投げる」から**「狙撃銃をチャッと構える」**に変更した(ユーザーが、新しく2つダウンロードした)。古い2つ(ショット・手裏剣)は、使わなくなったので、ゲームには埋め込まない(`se-raw/` には、元のファイルが残っている)。素材は、いまも **9個**。
- 音量: 拳銃は、平均 -22.8dB → 倍率 1.4。狙撃銃は、平均 -27.4dB で小さいが、**割れない**よう、ピークが -0.5dB 以内に収まる倍率 2.0 にとどめた(平均 約 -21dB と、ほかよりやや小さい)。
- 実ブラウザで、隙みせを打つと 1.38秒の素材(拳銃)・引き直しで 1.04秒の素材(狙撃銃)が鳴ることを確認した。**聞こえ方は、私には確かめられない**。
