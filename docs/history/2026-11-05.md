## やったこと

### 1. 開発前の確認(スキル)
- claude.ai 側で有効なプラグイン: フロントエンドデザイン / Remotion(動画)。
- この PC の Claude Code では、どちらも一覧に出ていなかった(前回の教訓 8 と同じ)。ユーザーに知らせた。
- ユーザーが `npx skills` で `frontend-design` を入れ、セッションを開き直したところ、一覧に出た。以後、UI の設計に使った。
- Remotion は PV を作るときだけ必要。今回は入れていない。

### 2. 企画の整理
- 企画ファイルは AI Studio の書き出し(JSON)で、同じ文章が重複して入っていた。会話だけを取り出し、`企画メモ原文.md` にした。
- 決まっていること・私が決めたこと・未決を分けて、`企画書.md` にした。

### 3. 作ったもの
- 構成: 静的ファイルのみ(サーバー・ビルド・ログインなし)。詳細は `設計メモ.md`。
- 6人の NPC(ナナシ / アグリー田中 / 激おこ太郎 / ぼくちゃん / めんへら子 / ID:真・論客)と、15枚のカード。
- 爽快モード(カード)とリアルモード(ローマ字入力・誤字・連投で流す)。
- 掲示板 UI、奥に見える NPC(気持ち5段階 + 前兆の動き)、弾幕(5・10・20コンボで増える)、論破カットイン、敗北のアスキーアート、記録の保存。
- 配布用フォルダを作るスクリプト(`scripts/build.sh`)。

### 4. 途中で直したこと
- 外したときの罰が軽く、でたらめ連打でも約半分勝てた。外すと -8 から -11 にし、特攻の支持率の増え方を減らし、カードの配りの偏りを弱めた。結果、でたらめ連打は20回中0〜1回しか勝てない。
- 得点の時間ボーナスが大きく、腕前の差が出なかった。式を直し、自動プレイの点数分布からランクの基準を決めた。
- 最初から選ばれているスレを1回クリックすると、モード選択の前に開始してしまった。クリックは選ぶだけにし、開始はボタン・ダブルクリック・Enter にした。
- スマホで手札の5枚目が切れていた。カードの配置を直した。
- ヒントの札がすべて灰色だった(CSS の優先順位)。直した。
- めんへら子の髪が背景に溶けていた。色を明るくした。
- 最初の NPC が3発で倒れた。NPC のメンタルを2〜3割増やした。

## 確かめたこと
- `node tests/run.js`: 164項目すべて成功。
  - データの整合、ローマ字入力(別の打ち方・「っ」「ん」・Backspace)、手札の絞り込み、同じ seed なら同じ展開、特攻・外し・いなし、コンボ・即レス、放置、誤字(つっこみ・連投で消える)、引き直し、勝敗、特殊カードの条件。
  - 自動プレイ: 腕前が良ければ全 NPC に勝てる(17〜20/20)。でたらめ連打では勝てない。何もしなければ負ける。
- 実ブラウザ(Chromium)で、PC(1280×800・1024×640)とスマホ(390×844)の幅を撮って確認。
  - タイトル、対戦、リアルモードの入力(途中・送信可・誤字)、20コンボの弾幕、論破のカットイン、敗北のアスキーアート、結果、一時停止(止まる・再開できる)。
  - 爽快・リアルの両方で、最後まで遊び、「もう一回」「スレ一覧へ」まで通した。ブラウザのエラー記録は空。
  - NPC の全表情・全動き・6人の見た目を一覧にして確認。
- `scripts/build.sh`: 参照先が全部 `public/` に入ることを確認。
