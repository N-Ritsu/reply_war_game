### 2. 企画の整理

### 3. 作ったもの
- 構成: 静的ファイルのみ(サーバー・ビルド・ログインなし)。詳細は `設計メモ.md`。
- 6人の NPC(ナナシ / アグリー田中 / 激おこ太郎 / ぼくちゃん / めんへら子 / ID:真・論客)と、15枚のカード。
- 爽快モード(カード)とリアルモード(ローマ字入力・誤字・連投で流す)。
- 掲示板 UI、奥に見える NPC(気持ち5段階 + 前兆の動き)、弾幕(5・10・20コンボで増える)、論破カットイン、敗北のアスキーアート、記録の保存。
- 配布用フォルダを作るスクリプト(`scripts/build.sh`)。

### 4. 途中で直したこと
- 外したときの罰が軽く、でたらめ連打でも約半分勝てた。外すと -8 から -11 にし、特攻の支持率の増え方を減らし、カードの配りの偏りを弱めた。結果、でたらめ連打は20回中0〜1回しか勝てない。
- 得点の時間ボーナスが大きく、腕前の差が出なかった。式を直し、自動プレイの点数分布からランクの基準を決めた。
- 最初から選ばれているスレを1回クリックすると、モード選択の前に開始してしまった。クリックは選ぶだけにし、開始はボタン・ダブルクリック・Enter にした。
- スマホで手札の5枚目が切れていた。カードの配置を直した。
- ヒントの札がすべて灰色だった(CSS の優先順位)。直した。
- めんへら子の髪が背景に溶けていた。色を明るくした。
- 最初の NPC が3発で倒れた。NPC のメンタルを2〜3割増やした。

## 追記: UI の刷新(同日・2回目の依頼)

### 依頼
- 見てみたが、UI を刷新してほしい。全体的にレベルが低い。もっと見やすく、レスは誰が打っているのか分かりやすく、こちらの攻撃が相手にダメージを与えているエフェクトも大きく分かりやすく。ゲームなので、リアルさよりも爽快感と分かりやすさ重視。

### やったこと
- 方針を変えた: 「本物の掲示板らしさ」→「マンガのコマのようなポップな見た目」(`設計メモ.md` の 4-1)。
- 画面を作り直した(`index.html`・`css/style.css`・`js/ui.js`。エンジンと入力判定は変更なし)。
  - 左にアリーナ(相手を大きく)、右にログ(チャット風)、下に手札、上に HUD。
  - 誰が打ったか: 相手=左・赤・顔アイコン / 自分=右・青・顔アイコン。
  - ダメージの演出: カードの文字が飛ぶ → 着弾(爆発・集中線・斬撃・ヒットストップ・画面の揺れ)→ 巨大なダメージ数字。メンタルのゲージは相手の真下に置き、白い残像で減りを見せる。
  - 外したら跳ね返って自分に当たる。スルー・誤字のつっこみも、相手のレスが自分に飛んでくる。
  - 返信待ちの先頭を黄色い枠で強調。ヒントありなら、いま効くカードが光る。
  - タイトルは、顔アイコン付きの相手の一覧と、大きな相手のプレビュー。結果・遊び方の窓も同じ見た目にそろえた。
  - 弾幕の層を、パネルの裏に回した(ログの文字が隠れない)。
- 効果音に、飛んでいく音・着弾(ダメージに応じて重く)・跳ね返りの音を足した。

### 途中で直したこと
- 相手の枠の影が「LIVE」の文字にまで付き、二重に見えた。枠の箱に影を付けるようにした。
- スマホで「引き直し」ボタンが文字に重なった。アイコンだけにして、上の帯に移した。
- スマホでダメージ数字が大きすぎた。アリーナの大きさに合わせて縮めるようにした。
- 「即レス！」の札がコンボ数字に重なった。位置をずらした。
- 1コンボ目では数字を出さないようにした(コンボは2から表示)。

### 確かめたこと
- `node tests/run.js`: 164項目すべて成功(エンジンは変更なし)。
- 実ブラウザ(Chromium)で、PC(1280×800・1920×1080・1024×640)、タブレット(768×1024)、スマホ(390×844)を撮って確認。
  - タイトル、対戦(前兆・返信待ち・攻撃の飛翔と着弾・外したときの跳ね返り・高コンボ)、リアルモードの入力、論破のカットイン、敗北の AA、結果、遊び方の窓。
  - 爽快・リアルの両方で、最後まで遊び、「もう一回」「相手を選びなおす」まで通した。ブラウザのエラー記録は空。
