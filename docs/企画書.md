# 激闘!レスバトル!(仮題) 企画書

企画の元は、AI との壁打ちの記録(`企画メモ原文.md`)。ここでは「決まっていること」「実装で私が決めたこと」「未決」を分けて書く。

## 1. ゲームの概要

- **種類**: ブラウザで遊ぶ、1人用の対戦カードアクション(PC・スマホ)。
- **舞台**: 匿名掲示板。プレイヤーは掲示板で、画面の奥にいる NPC とレスバをする。
- **売り**: スピード感と爽快感。相手のレスの種類を瞬時に見極め、効くカードを叩きつける。
- **見せ場**:
  - 画面の奥に NPC が見える(相手の Web カメラが丸見えという見立て)。焦り具合が見た目で分かり、動きが前兆にもなる。
  - 特攻を重ねると、ニコニコ動画風の弾幕が増えていく。
  - 勝つと「論破!」のカットイン、負けると煽りのアスキーアートが暴れる。

## 2. 企画で決まっていること

### 2-1. 基本の流れ
- 対 NPC 戦。NPC がレスで攻撃してくるので、こちらもレスを返す。
- 手札は5枚ほど。ランダムに配られる(例: 「効いてて草」「めっちゃ早口で喋ってそう」「図星だったかな?w」「それってあなたの感想ですよね?」)。
- カードごとに、効く場面(特攻)がある。
  - 「めっちゃ早口で喋ってそう」は、相手が長文のとき。
  - 「それってあなたの感想ですよね?」は、感情論のとき。
- 特攻でない場面で使うと、劣勢に傾く。
- 使わない言葉は**リロード**(引き直し)できる。待ち時間が発生する。

### 2-2. 勝ち負けと演出
- 特攻を決めると観衆の支持がこちらに傾き、ミスや放置で相手に傾く。
- 特攻を**連続**で当てると**コンボ**になる。コンボが増えると、**弾幕**(観衆のコメント)が増える。
- とどめは「論破!」のカットイン。負けると、めちゃくちゃ動く煽りのアスキーアートが出る。

### 2-3. 2つのモード
- **爽快モード**: カードを選んで使う(マウス・タップ)。
- **リアルモード**: カードと同じ内容をキーボードで打ち込むと発動する(寿司打のイメージ)。

### 2-4. 誤字のルール(リアルモード)
- 誤字を直してから打ち込むこともできる。ただし遅くなって、相手のペースになる。
- 誤字のまま打つと、相手に付け込まれる。
- 誤字は、**指摘される前に次の攻撃を仕掛けられればセーフ**。

### 2-5. 画面
- 匿名掲示板風にする(レスに番号とアンカー `>>14` が付く、など)。
- パソコンの奥に相手の NPC が見えるようにして、焦り度合いなどが分かる。
- (2026-11-05 の方針変更)ゲームなので、**リアルさよりも爽快感と分かりやすさ**を優先する。掲示板の見た目の再現にはこだわらない。

## 3. 実装で私が決めたこと(企画書にはなかった部分)

あとから変えてよい。変えるときは、この表と `設計メモ.md` を直す。

| 項目 | 決めた内容 | 理由 |
|---|---|---|
| 勝ち負けの数値 | 相手の**メンタル**を0にするか、**観衆支持率**を100%にすると勝ち。支持率が0%で負け。支持率は50%から始まる。 | 壁打ちの案(支持率ゲージとメンタル HP の両方)をそのまま採用した。 |
| レスの種類 | 長文 / 感情論 / ブーメラン(矛盾)/ 論点ずらし / 短文連打 / 自演 の6種。 | 壁打ちで出た分類。短文連打はキッズ NPC 用、自演はボス用に足した。 |
| 外したとき | 支持率が11下がり、コンボが切れる。 | 「劣勢に傾く」の具体化。 |
| 放置したとき | 返信の猶予(3〜7秒)を過ぎると、支持率が下がりコンボが切れる。 | 「相手のレスを放置すると相手に傾く」(壁打ち案)の具体化。 |
| いなすカード | 「ふーん、で?」「そっか」。外れないが威力は小さい。放置は防げる。 | 壁打ちの「汎用防御カード」。 |
| 「効いてて草」 | 相手のメンタルが半分以下なら特攻。余裕があるうちに使うと外れ。 | 奥の NPC の焦り具合を見る理由になる。 |
| 即レス | レスが来てから、爽快モード1.8秒・リアルモード4.5秒以内に返すと威力1.25倍。誤字ありは対象外。 | 壁打ち案の「即レスボーナス」。リアルモードは打つ時間を見込んで長くした。 |
| コンボ | 特攻1回ごとに威力+10%(最大+100%)。5・10・20コンボで弾幕の量と大きさが段階的に増える。 | 5コンボで「草」、10で「大草原」、20で画面が見えなくなる(壁打ち案)。 |
| 引き直し | 1枚ずつ、待ち時間2.6秒。その間そのスロットは使えない。使ったカードの補充は0.65秒。 | 相手が長文を打っている最中(前兆の間)に引き直す、という駆け引きを作る。 |
| 誤字のつっこみ | 誤字つきで送ると、奥の NPC の頭上に「!?」が出る。2.4秒以内に次のレスを送れば消える。間に合わないと支持率が12下がる。 | 「ツッコミ待機時間」と「連投でキャンセル」(壁打ち案)の具体化。 |
| 前兆 | 相手が次のレスを出す約1秒前に、奥の NPC が種類に応じた動きをする。長文=両手を上げて深呼吸、感情論=真っ赤、ブーメラン=にやり、論点ずらし=目をそらす、短文連打=指が高速、自演=別の端末を見る。 | 「敵のモーションを見てから対策する」(壁打ち案)。 |
| ヒント | レスの種類の札と、カードの「○○向き」の札を表示する。タイトル画面でオフにできる。 | 初めてでも遊べるように。慣れたら、見た目と NPC の動きだけで見極める。 |
| 誰が打ったか | ログをチャット風にする。相手=左・赤・相手の顔 / 自分=右・青・自分の顔。 | 掲示板の素の見た目だと、誰のレスか分かりにくかった(ユーザーの指摘)。 |
| ダメージの見せ方 | 攻撃すると、カードの文字が相手に飛んで着弾する。爆発・斬撃・ヒットストップ・巨大なダメージ数字・画面の揺れ。外すと跳ね返って自分に当たる。 | 「こちらの攻撃が効いている」を大きく分かりやすく、というユーザーの指摘。 |
| いま返す相手 | 返信待ちの先頭を黄色い枠で強調。ヒントありなら、いま効くカードも光る。 | 見極めの学習を助ける(ヒントはオフにできる)。 |
| 入力方式 | ローマ字入力。「si / shi」のような別の打ち方もすべて受け付ける。IME は切って半角英数で。 | 寿司打と同じ。IME の変換を挟むと判定できないため。 |
| 記録 | クリア済みのランク(S/A/B/C)と最高得点を、爽快・リアルで別々に、ブラウザの中に保存する。 | サーバーを持たないため。 |
| スマホ | 爽快モードのみ。リアルモードは、キーボードが無い端末では選べない。 | キーボードが必要なため。 |
