# 激闘!レスバトル!(仮題) 企画書

企画の元は、AI との壁打ちの記録(`企画メモ原文.md`)。ここでは「決まっていること」「実装で私が決めたこと」「未決」を分けて書く。

## 1. ゲームの概要

- **種類**: ブラウザで遊ぶ、対戦カードアクション(PC・スマホ)。NPC と戦う1人用に加えて、プレイヤー同士のレート戦(サーバー使用)がある。
- **舞台**: 匿名掲示板。プレイヤーは掲示板で、画面の奥にいる NPC とレスバをする。
- **売り**: スピード感と爽快感。相手のレスの種類を瞬時に見極め、効くカードを叩きつける。
- **見せ場**:
  - 画面の奥に NPC が見える(相手の Web カメラが丸見えという見立て)。焦り具合が見た目で分かり、動きが前兆にもなる。
  - 特攻を重ねると、ニコニコ動画風の弾幕が増えていく。
  - 勝つと「論破!」のカットイン、負けると煽りのアスキーアートが暴れる。

## 2. 企画で決まっていること

### 2-1. 基本の流れ
- 対 NPC 戦。NPC がレスで攻撃してくるので、こちらもレスを返す。
- 手札は5枚ほど。ランダムに配られる(例: 「効いてて草」「めっちゃ早口で喋ってそう」「図星だったかな?w」「それってあなたの感想ですよね?」)。
- カードごとに、効く場面(特攻)がある。
  - 「めっちゃ早口で喋ってそう」は、相手が長文のとき。
  - 「それってあなたの感想ですよね?」は、感情論のとき。
- 特攻でない場面で使うと、劣勢に傾く。
- 使わない言葉は**リロード**(引き直し)できる。待ち時間が発生する(約1秒)。
- (2026-11-05 の追加)相手のレス1回に対して、**こちらは何回でも攻撃してよい**。連発できるが、やりすぎると相手に「必死で草」などと攻撃し返される。特に最後の詰めでは連発しやすく、反撃されない程度の連発もできる。
- (同上)長文は相手の**入力待ちが長く**、短文は短い。長文を待っている間、待ち時間の長さに応じて「黙っちゃった？」のような攻撃が使える。

### 2-2. 勝ち負けと演出
- 特攻を決めると観衆の支持がこちらに傾き、ミスや放置で相手に傾く。
- 特攻を**連続**で当てると**コンボ**になる。コンボが増えると、**弾幕**(観衆のコメント)が増える。
- とどめは「論破!」のカットイン。負けると、めちゃくちゃ動く煽りのアスキーアートが出る。

### 2-3. 2つのモード
- **爽快モード**: カードを選んで使う(マウス・タップ)。
- **リアルモード**: カードと同じ内容をキーボードで打ち込むと発動する(寿司打のイメージ)。
- (2026-11-06 の変更)2つのモードの違いを、**手札の有無**にした。
  - 爽快: **ボタン1つ**で作動できるが、**5枚のカードでやりくり**する必要がある(手札は使うと補充され、引き直しもできる)。
  - リアル: **タイピングが必要**だが、**カードに縛られず**に攻撃できる。手札はなく、**全部の言葉**を自由に打ち込める。

### 2-4. 誤字のルール(リアルモード)
- 誤字を直してから打ち込むこともできる。ただし遅くなって、相手のペースになる。
- 誤字のまま打つと、相手に付け込まれる。
- 誤字は、**指摘される前に次の攻撃を仕掛けられればセーフ**。

### 2-5. 画面
- 匿名掲示板風にする(レスに番号とアンカー `>>14` が付く、など)。
- パソコンの奥に相手の NPC が見えるようにして、焦り度合いなどが分かる。
- (2026-11-05 の方針変更)ゲームなので、**リアルさよりも爽快感と分かりやすさ**を優先する。掲示板の見た目の再現にはこだわらない。

### 2-6. プレイヤー対戦(2026-11-06 に追加)
- NPC 戦のほかに、**プレイヤー同士の対戦**を入れる。NPC のレス(**隙みせ攻撃**)に攻撃するのではなく、**プレイヤーも隙みせ攻撃を打つ**。
- **攻撃は、相手のメンタルにダメージ。隙みせ攻撃は、自分のスレの盛り上がりを上げる。** 盛り上がりは時間で減る(定期的に打つ)。隙みせ攻撃は、**1回打ったら2秒以上あける**。種類は、長文・感情論・ブーメラン・論点ずらし・短文連打の5種類から選ぶ。
- **各自の盛り上がりが、自分の攻撃ダメージの倍率**(0で0.3倍、100で1.8倍)。隙みせは、相手に狙われる的でもあるので、打ちすぎず、打たなすぎず。
- **盛り上がりが 0 になったら、その時点で負け**(2026-11-08)。40 を切ると、ゲージが赤く震え、20 を切ると、画面全体が赤く震えて、ゲージと隙みせ攻撃が強調される。**同じ種類の隙みせ攻撃は、2連続では打てない**。
- 爽快でもリアルでも対戦できる。**リアルのほうがダメージが大きい**。リアルでも、隙みせ攻撃は、選んでクリックで送信する。**リアルモードは、PC(キーボードのある端末)だけ。スマホは、爽快(カード)のみ**。
- **対戦の誤字**(2026-11-08): 誤字つきで送っても、それだけではダメージにならない。チャット上の**誤字の部分が強調され、相手がそこをクリック(タップ)して指摘したらダメージ**(5秒以内・40・コンボも途切れる)。
- **レート式**(Elo)。ランダムマッチ(レートの近い人)。**5秒待っても相手が見つからなければ、同じくらいのレートの人を1人選んで、その人の動き(攻撃・誤字・隙みせの回数など)に似せたボット**が相手をする(2026-11-08)。相手の名前は出す(ボットの場合も、元になった人の名前)。**レートは、遊んだ側だけ動く**。記録のある人がいなければ、標準のボット(レートなし)。
- 詳細は [対戦設計.md](対戦設計.md)。
- **広告(2026-11-08、初期状態は無効)**: バナーは全画面の下。全画面広告は NPC 戦 3 回につき 1 回。レート戦は 1 日 3 回まで無料で、4 回目からはリワード広告を見ると 3 回遊べる。**広告削除(100円)**で、広告も回数制限もなくなる。詳細は [広告の設計.md](広告の設計.md)。
